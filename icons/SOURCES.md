# Источники значков

Значки сервисов взяты из [Simple Icons](https://github.com/simple-icons/simple-icons)
версии 16.35.0. Данные Simple Icons распространяются под CC0 1.0.

Сами логотипы — товарные знаки их владельцев. Каталог использует их только для
обозначения соответствующего сервиса. Discord Bridge не связан с этими компаниями и
не является их официальным продуктом.

Значки нарисованы фирменным цветом на светлой плитке 128×128 PNG, чтобы одинаково
читаться в светлой и тёмной темах. Контуры не менялись.
